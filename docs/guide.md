# 从这里开始

pokeldn 通过本地无线通信，与 Switch 或 Switch 2 上的宝可梦游戏进行交换。
通过 USB 连接的 ESP32 开发板负责无线通信，无需在游戏机上安装任何内容。

<a id="what-you-need"></a>
## 准备事项

- 带 USB 串口桥接芯片的经典 ESP32（ESP32-D0WD、WROOM-32E），或通过原生 USB 端口
  连接的 ESP32-S3、ESP32-C3、ESP32-C6。均使用 2.4 GHz，不支持 S2。
  Seeed Studio XIAO ESP32C3 需要连接随附天线，XIAO ESP32C6 使用内置天线。
- USB 数据线。仅支持充电的线缆不会显示串口。
- 从自己的 Switch 导出的 `prod.keys`，首次使用时选择一次即可。
- “游戏”页提供的七款游戏之一。

<a id="first-run"></a>
## 首次使用

1. 打开“开发板”页，连接开发板，点击“无线”旁的“安装”。应用识别芯片、写入固件后会自动
   检查开发板，收到响应后，页面顶部显示固件已更新。
2. 打开“游戏”页，选择游戏和工具。“主机”工具等待游戏机加入，“加入”工具搜索游戏机创建的组。
3. 在“用于交换的宝可梦”中搜索物种并点击“生成”。PKHeX 会生成适用于该游戏的合法宝可梦，
   初训家使用“设置”中填写的训练家。
4. “会话”面板的“开始前”会列出尚缺少的条件，并提供相应按钮。按“在游戏机上操作”中的步骤
   设置游戏机，然后点击“开始”。

带两个 USB 端口的 ESP32-S3、C3、C6 必须通过标有 USB 的原生端口与应用通信。
通过另一个 COM 或 UART 端口刷写固件虽然可以成功，但开发板不会响应应用，“开发板”页会提示
这种情况。连接多个开发板时，使用“使用此开发板”选择会话所用的设备。

物种下方的“更多选项”可设置性格、特性、性别、携带道具、精灵球、亲密度、个体值和努力值；
Let's Go 使用觉醒值，传说 阿尔宙斯使用奋斗等级。留空表示随机。列表仅提供该物种在当前游戏中
合法可用的选项，PKHeX 判定组合不合法时会拒绝生成并显示原因。“设置 → 显示高级设置”中的
“允许不合法的宝可梦”可以放开这些限制，默认关闭。

只有“设置”中的训练家与游戏机玩家一致，交换后的宝可梦才会保留亲密度；火红／叶绿每次交换
都会将亲密度设为 70。

物种下方的“添加交换”可在一次会话中按顺序交换最多六只宝可梦。完成一次交换后，主机会提供
下一只。所有交换工具都支持队列，每次交换收到的宝可梦分别保存为独立文件。

可以把文件拖入应用：将宝可梦文件或 Showdown 队伍文本（`.txt`）拖入交换卡片会填入该卡片，
拖到“添加交换”上则按文件加入队列。将礼物文件拖到礼物卡片会打开它；将 `.bin` 固件拖到
“开发板”页的固件卡片，在确认后即可安装。

收到的宝可梦保存在 `Documents/pokeldn/Received`，同时存入“银行”。银行的加号按钮或网格拖放
支持导入宝可梦文件及整个游戏存档；每只合法宝可梦只导入一次，原文件保持原样。跨世代传入时，
会按 HOME 的传入规则移除不允许携带的道具并忘记秘传招式。

<a id="free-up-storage"></a>
## 释放存储空间

“设置 → 存储”显示可以释放的空间。点击“清理本地文件”并确认，可删除会话记录、日志、临时
交换文件和未使用的已生成宝可梦。需要提交问题报告的记录应先保存。已接收的宝可梦、选中的
交换文件、密钥、固件和设置会保留。请先结束运行中的任务，再执行清理。

<a id="backup-and-restore"></a>
## 备份与恢复

在“设置 → 存储 → 备份与恢复”中，点击“备份…”可将设置、银行、收到和生成的宝可梦、存档、
GTS 挂牌和宏保存为一个 ZIP 文件。备份不包含游戏机密钥或插件。

点击“恢复…”并选择备份 ZIP 后，应用会列出文件数和大小供确认。恢复前会在应用数据目录的
`backups` 文件夹中备份当前文件，最多保留最近三份恢复前的备份。恢复会替换同名文件，保留其他
文件。恢复的设置在下次启动 pokeldn 时生效。

<a id="firered-and-leafgreen-language"></a>
## 火红／叶绿的语言

神秘礼物的“游戏机”卡片可选择版本和卡带语言。卡带语言默认“与设置相同”，采用“设置”中的
训练家语言。日文卡带必须选择日语，才会在游戏的“朋友”列表中列出 POKELDN。游戏机加入后
报告卡带代码，应用据此选择该卡带的礼物脚本和 RAM 地址。两个版本均支持英语、法语、德语、
意大利语、西班牙语和日语。

当礼物因版本或语言而异时，保存原生 `.wc3` 文件需要选择卡带版本。`.pokegift` 可以保存全部
版本，并在游戏机连接时自动选择正确版本。训练家语言表示 pokeldn 在连接中报告的语言，也作为
卡带语言的默认值；卡带的实际版本和地址仍在连接后从游戏代码读取。应用显示语言单独设置。

<a id="basic-and-advanced"></a>
## 基本与高级

“基本”显示日常使用所需的字段，应用会自动采用各游戏已经验证的设置。“高级”列出当前会话
支持的全部选项及各自说明，其中填写的值会覆盖“基本”设置。除非指南或问题报告要求，否则无需修改。

不常用的设置位于“高级”顶部，包括自动结束会话的时限、无线信道和“每次运行生成新 PID”。
新 PID 可让已经收到过该宝可梦的存档再次接收；对必须保留固定 PID 的文件，例如部分活动宝可梦，
应关闭此选项。

开启“保存游戏机展示的宝可梦”后，交换画面中展示的记录会写入与接收目录 `Received` 同级的
`Shown` 文件夹，即使随后取消交换也会保存，可用 PKHeX 检查种子或合法性。交换收到的记录
只有在交换完成后才写入 `Received`，用于接收列表和银行。

<a id="your-own-pokemon-files"></a>
## 使用自己的宝可梦文件

“或使用宝可梦文件”可以打开从 PKHeX 导出的文件。应用会通过 PKHeX 检查，并在发送前显示其
合法性。不合法的宝可梦在对方游戏绘制时可能导致游戏崩溃。

<a id="mystery-gift"></a>
## 神秘礼物

神秘礼物工具提供四种主要方式：

- “使用预设”发送已经配置好的礼物。剑／盾的“官方活动”支持搜索真实活动卡片，包括宝可梦、
  道具、服装和对战点数。
- “自行构建”打开表单。火红／叶绿支持神奇卡片、正文、发放 NPC、礼物效果、神奇新闻和 ARM
  代码；剑／盾支持宝可梦、蛋、道具和对战点数。
- “打开文件”可发送他人分享的 `.pokegift`、火红／叶绿的 `.wc3` 或剑／盾的 `.wc8`。
- “自定义”将预设转入可以编辑的表单。

“发送前”显示游戏机将获得什么、何时生效及支持哪些卡带。问题以红色显示，解决前无法点击“开始”。

火红／叶绿的“游戏增强功能”可改变运行中的游戏，例如加速或增加跟随宝可梦。选择并发送后立即
生效，游戏重启后停止。要在重启后恢复，先启用“保存增强功能供以后使用”并发送增强功能，再发送
“由妈妈恢复增强功能”。每次重启后，与真新镇家中的妈妈对话即可恢复。跟随宝可梦会始终保存。
收到其他神奇卡片后，妈妈的礼物会被替换，需要重新发送恢复礼物。

“读取存档”会在会话日志中显示结果。训练家 ID（TID）是训练家卡片上的编号，里 ID（SID）通常
不会直接显示。同行队伍读取结果包含最后保存的队伍、性格、六项个体值（0 至 31）和努力值。
这些读取工具不改变存档和神奇卡片，训练家与队伍工具还会把读取数据保存到“已接收”目录。

“游戏机代码”在游戏接收礼物时于游戏内部执行。“离线检查”会先在模拟游戏机上运行，可能导致
菜单无响应的代码会被拒绝。原生代码可以改变游戏或存档，因此只应发送已经检查过来源和行为的代码。

“保存礼物文件”将当前礼物保存为可复用或分享的文件，不需要连接开发板。

火红／叶绿的“你的存档”可以把整个存档从 Switch 复制到电脑，或恢复到 Switch。
备份保留游戏机原存档，并按训练家命名显示在存档列表中。恢复时，游戏机会先逐部分检查新数据，
加载并保存；任何步骤失败都会保留原存档。恢复前请先备份。默认需要 PKHeX 判定整个同行队伍合法，
也可以手动开启“仍然恢复”。

存档保存在 `Documents/pokeldn/Saves`。可以重命名以便区分，导出 `.sav` 供模拟器或 PKHeX 使用，
通过加号或拖放导入 `.sav`。“查看与编辑”显示训练家、同行队伍和电脑盒子，可修改姓名、金钱和
代币，调整或移除队伍成员，为当前训练家生成宝可梦，并检查盒子中的合法性。“保留为新存档”会
生成独立副本，原存档保持原样。

<a id="whats-new-in-0450"></a>
## 0.45.0 的新增操作

- 游戏侧栏按交换、神秘礼物、团体战等活动分组。先选活动，再在中间选择 pokeldn 的角色、连接方式及模式（主持表示游戏机加入，加入表示游戏机主持）。
- 《剑／盾》支持“Wi-Fi（无需开发板）”连接；电脑与游戏机须处于同一网络，游戏机需先启用 LAN 模式。
- 交换时可以不指定宝可梦，开始任务后由 PKHeX 随机生成一只合法宝可梦。需要通过交换进化时，可启用“交换后送回”。
- 银行新增图鉴、排序、筛选、多选和批量导出，也支持导入 PKSM 的 `.bnk` 银行。
- GTS 每条挂单可要求最多三种宝可梦，每种可单独限定异色；对方满足任意一种即可回应。
- 在“设置 → 初训家”中点击“查找我的训练家”，可使用上一次交换读取到的训练家信息。
- 神秘礼物可保存到开发板，使其脱离电脑后独立分发。界面会说明当前游戏所支持的方式。
- 火红／叶绿的“异色传说宝可梦”支持超梦和三圣鸟；两者的按键步骤不同，见下方 [0.46.0 使用提示](#whats-new-in-0460)。

语言包安装和选择后需要重启程序。游戏记录中的文字、昵称、文件路径及连接码保持原值。

<a id="when-a-run-fails"></a>
## 任务失败时

- 点击“停止”，退出游戏机的搜索画面后重新搜索。多数游戏会短暂保留失效的会话。
- 每次重试只改变一个设置，便于确定原因。
- 在“设置”中启用“记录每次会话”，通过“打开记录文件夹”查看记录，并将最新记录附在问题报告中。


<a id="whats-new-in-0460"></a>
## 0.46.0 使用提示

- 在“设置”中启用“显示开发板屏幕”，即可在会话面板顶部查看连接流量、交换宝可梦、神秘礼物卡片及团体战大厅。开发板无需接入实际屏幕。像素内容是固件屏幕的镜像，保留固件原有文字。
- 火红／叶绿的训练家语言默认“与设置相同”。神秘礼物另有“卡带语言”；日文卡带需要选择日语，才能在朋友列表中找到 POKELDN。显示语言与卡带、训练家语言分别设置。
- GTS 会以时钟标记已报价、等待挂牌方回应的挂牌，并显示“你提供的宝可梦”。其他玩家仍可报价；挂牌方下次打开应用时处理最早的有效报价，其余宝可梦退回银行。
- 超梦的异色自动按键：面向超梦先自行按 A，叫声阶段不要按键，等待程序在异色帧按 A。此前不要走动或进行野生对战。
- 急冻鸟、闪电鸟、火焰鸟：站在前方，前情回顾后地图出现时轻按上方向键，再按住 B；倒计时过零而未触发时继续按住，等待下一轮。
- 绿宝石的交换与神秘礼物研究已拆分至[交换与联合房间](rse_link.md)、[神秘礼物](rse_gift.md)。Switch 构建版交换后使用五轮待机；它仍是研究用构建版，不代表正式发行。


<a id="whats-new-in-0480"></a>
## 0.48.0 使用提示

- 角色栏以 pokeldn 为主体：“主持”时游戏机加入 pokeldn，“加入”时 pokeldn 加入游戏机。
- 银行可多选宝可梦后批量“发送到游戏”，查看各游戏能接收的数量，再加入交换工具的空余队列。每个队列最多六只，按银行当前顺序加入；已排队的宝可梦保留在原队列。
- 银行搜索同时匹配显示语言和英文的种类、昵称、性格、特性、精灵球及游戏名称；排序、筛选和图鉴筛选会保存在设置中。
- 会话面板显示等待、已连接和已离开的状态。等待超过 60 秒时，请核对游戏机画面与操作步骤是否一致。
- 在“设置”启用“重试失败的交换”后，游戏机未加入、开发板断开或加入失败会在 15 秒后重试，仅使用尚未交换的宝可梦，最多连续三次。点击“不再重试”、开始任务或切换工具可取消等待。
- 密钥文件必须包含 aes_kek_generation_source、aes_key_generation_source、master_key_00、master_key_12。缺少时界面列出缺失项，请选择自己游戏机导出的 prod.keys。
- 设置损坏时会先将原文件保留为 settings.json.bad，只重置无法读取的字段，并在启动时提示。请检查训练家和密钥设置。
- “设置 → 大字体”使应用文字增大 15%，重启生效。
- 键盘快捷键：macOS 用 Cmd，其他系统用 Ctrl；1–6 切换游戏、开发板、银行、GTS、手柄控制、文档；逗号打开设置，Enter 开始或重启会话，句号停止。
- 高级选项 --hold-after-trade N 指定最后一只队列宝可梦交换完成后等待 N 秒再退出。默认等待游戏机离开或任务达到时限；不同游戏的退出表现见对应文档。


<a id="whats-new-in-0530"></a>
## 0.53.0 使用提示

- “设置 → 初训家”可启用“为每个游戏单独设置训练家”，再选择游戏编辑姓名、性别、语言、ID 和里 ID；未单独修改的游戏继续使用共用值。“查找我的训练家”在独立模式下读取所选游戏的最新训练家。
- 选择宝可梦后可指定形态；霜奶仙另有糖饰选项。“更多选项”新增遭遇来源、太晶属性、超极巨化和极巨化等级。实际可用项由 PKHeX 按游戏和种类提供。
- “个体值最大”“亲密度最大”和能力值最大按钮可以快速填写。努力值最大化会给基础能力最高的两项各分配 252，剩余分配给第三项。
- 导入宝可梦文件默认保留原初训家。启用“将我设为它的初训家”后，PKHeX 尝试使用当前游戏的训练家；固定活动训练家、或仅存在处理训练家时才合法的礼物不能随意改写。固定 PID 的遭遇更换初训家后可能改变异色状态，界面会说明结果。“清空”恢复到未指定宝可梦。
- 极巨团体战首领必须存在于巢穴中，且形态、超极巨化状态匹配。首领按巢穴种子生成，使游戏机捕获后的记录满足 PKHeX 的团体战检查；等级决定星级。高级选项 `--raid-boss-as-is` 直接使用文件自身数据，捕获后可能无法通过该检查。
- 高级参数 `--rom-transfer`、`--rom-live`、`--rom-base`、`--rom-no-boot` 用于研究中的 ROM 写入与启动。其最新测量、限制及完整步骤见 [Switch 构建版](rse_switch_build.md#delivery-without-atmosphere)；该研究页整篇使用最新英文。


<a id="whats-new-in-0540"></a>
## 0.54.0 使用提示

- 启用“为每个游戏单独设置训练家”后，双版本游戏会分别列出，例如火红与叶绿、剑与盾、朱与紫。未编辑的版本继承所属游戏的训练家；两个版本的训练家不同，工具上方会显示“你使用的版本”，本次任务采用所选版本的训练家。
- 宝可梦卡片中的下载图标可将已生成或已加载的宝可梦导出为对应游戏格式的文件；浏览器和手机应用也支持导出。关闭图标可清空当前选择，悬停可查看按钮说明。
- “集友圈 → 遭遇”新增“证章”，提供 42 种野生证章，默认为“无”。启用“仅合法遭遇”时，PKHeX 同时检查证章和地点的天气条件，并非任意证章都能出现在任意地点。
- 集友圈生成的宝可梦会在主机游戏自身野生宝可梦曾走过的地面上出现并游走；城镇中不会生成，距离主机超过 50 米或被发起对战后会补充到附近。具体研究与实机测量见[集友圈](sv_union_circle.md#crafted-encounters)。
- 启用“交换后送回”时，第一次交换后会显示操作卡片：在游戏机上再次交换，提供任意宝可梦，即可接回刚送出的宝可梦。
- 开发板安装后，检查收到响应会显示“已安装，可以使用”。


<a id="whats-new-in-0562"></a>
## 0.56.2 使用提示

- “设置 → 高级 → 发射功率”可选择“自动（默认）”、最大 20 dBm、15 dBm、11 dBm 或 8.5 dBm。
  自动模式对所有 ESP32-C3 使用 8.5 dBm，对其他开发板使用驱动允许的最大功率；连续加入失败后，
  其他开发板还会以 8.5 dBm 再尝试一次，成功后在本次运行中沿用此功率。若需让 C3 使用最大功率，
  可手动选择“最大（20 dBm）”。固件 1.9.3 起在关联前设置发射功率上限。
- 开发板识别为无线固件并通过串口连接时，“开发板”页会显示“测试无线通信”。先让 Switch
  在本地交换或连接游玩菜单中等待，再阅读确认对话框并开始测试。开发板先在信道 1、6、11 上
  监听约 20 秒，随后在信道 6 广播 `POKELDN-TEST`，持续 60 秒。请在靠近开发板及离开几步的
  位置检查手机 Wi-Fi 列表是否能发现该名称。测试可能使开发板重启，结果保留在开发板日志中，
  可通过“复制开发板详情”一并复制。
- 无线测试日志中，能发现 Wi-Fi 却找不到 Switch 时，先检查游戏机是否正在本地游玩菜单等待。
  完全收不到无线帧时，接收器或天线可能有问题；手机紧挨开发板也从未发现测试网络时，
  发射端可能有问题。诊断原理与限制见[ESP32 开发板](hardware_esp32.md#the-radio-test)。
- 剑盾加入交换时，会按 `--ladder-refresh` 指定的间隔重新发送确认消息对，并更新消息时钟，
  默认间隔为 1 秒，设为 0 关闭。该修复使涉及传说宝可梦的交换可以完成。极巨大冒险加入工具
  也能识别针对特定传说宝可梦的大厅。参数说明可在对应工具的“高级”中查看。

<a id="whats-new-in-0580"></a>
## 0.58.0 使用提示

- 开启“允许不合法的宝可梦”后，生成器仍会先尝试合法遭遇。没有符合要求的合法结果时，
  会按所选条件生成，并在卡片上显示“不合法”和判定原因。游戏中不存在的种类和形态仍不可用。
  GTS 仍只接受合法宝可梦。0.58.0 的界面已加载的选项可能不会随开关立即刷新，
  并且开启后仍可能拒绝导入不合法的文件。
  损坏的宝可梦可能使游戏在显示它时崩溃，请先备份存档。
- “更多选项”中的性别和部分开关可以直接点击所需值。重新打开设置时，每个游戏的训练家编辑器
  会定位到最近修改的版本。
- 用无线方式主持剑盾极巨大冒险时，先在游戏机上选择“邀请其他人”，再启动主机。pokeldn 会
  扫描并使用游戏机大厅的 LDN 场景。未找到时使用 50000；需要手动指定时可在“高级”中设置
  `--lair-scene`。LAN 连接的大厅匹配规则不受这一调整影响。
- 无线固件 1.10.0 起，开发板空闲且连续 30 秒未收到主机消息时进入待机。收到下一条消息时
  会自动唤醒。正在主持的网络、已保存的便携广播和进行中的会话会继续运行。

## 0.60.2 使用提示

- “设置 → 显示高级设置”中的“允许将不合法的宝可梦导入银行”默认关闭。开启后，银行可保留
  从文件或存档导入且被 PKHeX 判定为不合法的宝可梦，并标记为“不合法”。传送或交换仍由
  “允许不合法的宝可梦”控制，GTS 只接受合法宝可梦。
- 交换卡片可以打开其他游戏的宝可梦文件。PKHeX 会按 HOME 的规则转换到目标游戏，移除携带
  道具和第三、第四世代的秘传招式。目标游戏中不存在的种类或形态会被拒绝，并显示原因。
- 点击交换卡片的复制图标，可在其后加入一笔交换。程序会用相同选项重新生成原来由程序生成的
  宝可梦，使副本拥有独立的 PID。来自文件的宝可梦按原数据复制。
- 剑盾“神秘礼物 → 自行制作”的宝可梦礼物可以添加奖章。道具、精灵球和奖章列表会显示已缓存
  的图标。模拟神秘礼物列表显示活动标题的译文，按标题搜索时使用原始标题。
